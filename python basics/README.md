## 📚 Python Topics Covered

### 1. Variables
- Creating and declaring variables.
- Assigning and updating values.
- Variable naming rules.
- Multiple variable assignments.
- Using variables in calculations.

### 2. Data Types
- Integers (`int`)
- Floats (`float`)
- Strings (`str`)
- Booleans (`bool`)
- Lists (`list`)
- Tuples (`tuple`)
- Sets (`set`)
- Dictionaries (`dict`)
- Checking data types using `type()`.

### 3. Python Operators
- Arithmetic operators.
- Assignment operators.
- Comparison operators.
- Logical operators.
- Membership operators.
- Identity operators.
- Bitwise operators.

### 4. Conditional Statements
- `if` statements.
- `if-else` statements.
- `if-elif-else` statements.
- Nested conditions.
- Checking even and odd numbers.
- Comparing two numbers.
- Using logical conditions.

### 5. Loops
- `for` loops.
- `while` loops.
- Nested loops.
- `break` statements.
- `continue` statements.
- Iterating through lists.
- Generating multiplication tables.

### 6. Functions
- Defining functions using `def`.
- Calling functions.
- Parameters and arguments.
- Returning values using `return`.
- Functions with multiple parameters.
- Creating reusable blocks of code.

### 7. Data Structures
- Lists and list methods.
- Tuples and immutability.
- Sets and unique values.
- Dictionaries and key-value pairs.
- Adding, removing and accessing elements.
- Working with collections of information.

### 8. Object-Oriented Programming (OOP)

Understanding the four fundamental principles of OOP:

**Encapsulation**
- Protecting data.
- Controlling access to class attributes.

**Inheritance**
- Creating parent and child classes.
- Reusing methods and attributes.

**Polymorphism**
- Using the same method name with different behaviours.

**Abstraction**
- Hiding implementation details.
- Working with abstract classes and methods.

Other OOP concepts:
- Classes and objects.
- Constructors (`__init__`).
- Attributes and methods.
- Inheritance and abstract classes.

## ▶️ How to Run Python Programs

To run a Python program using Visual Studio Code:

1. Open the project folder in VS Code.
2. Open the Python file you want to execute.
3. Open the integrated terminal.
4. Run the following command:

```bash
py filename.py
```

Example:

```bash
py app.py
```
